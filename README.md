“斗魂战绩册”是一款 Windows 本地工具，可以连接正在运行的英雄联盟国服客户端，自动读取并统计个人斗魂竞技场赛后数据。
主要功能：

• 自动导入并按 gameId 去重保存对局
• 按英雄统计选取次数、吃鸡次数、吃鸡率和平均名次
• 展示游戏时长、KDA、金币、伤害、承伤、治疗和自我减伤
• 查看强化符文、装备、队友与对手阵容
• 多账号数据隔离和玩家名称隐私模式
• 最近对局分页浏览与最近 20 场名次趋势
• 所有数据默认只保存在本机

工具不读取游戏内存、不注入游戏进程、不修改客户端，也不会保存客户端临时认证令牌。
