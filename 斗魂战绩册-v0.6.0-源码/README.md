# 斗魂战绩册

Windows 国服《英雄联盟》斗魂竞技场个人统计工具。

当前版本：v0.6.0

## 当前功能

- 自动连接正在运行的腾讯国服客户端；
- 自动读取最近个人斗魂竞技场对局；
- 根据 `subteamPlacement == 1` 判断吃鸡；
- 按 `gameId` 自动去重；
- 客户端数据只读保存，不提供手动修改和删除入口；
- 按英雄统计选取次数、吃鸡次数、吃鸡率和平均名次；
- 英雄汇总支持点击任意表头切换升序/降序，默认按吃鸡数降序；
- 历史列表展示游戏时长和 KDA；
- 最近对局按每页 50 场加载，支持首页、上一页、下一页和末页；
- 对局详情分为本人、队友和对手三个页签；
- 队友与对手列表展示玩家 Riot ID、英雄、名次、KDA、伤害和承伤；
- 点选同局玩家可查看其金币、治疗、自我减伤、强化符文和装备；
- 玩家隐私模式可将 Riot ID 匿名显示为“队友 1、对手 1”；
- 从国服客户端读取英雄图标并缓存在本机，离线后仍可显示；
- 英雄汇总、最近对局和详情页参与者均展示英雄图标；
- 对手列表移除队伍文字列，通过交替底色和组间隔线保持分组；
- 对局时间统一按本机时区显示，旧数据无需重新导入；
- 展示当前连续未吃鸡场数、今日对局数和本周对局数；
- 展示最近 20 场名次变化折线图；
- 折线图在每个节点直接标注该场名次；
- 历史列表时间包含年份，便于长期积累和跨年查看；
- 底部状态灯显示客户端连接状态：绿色正常、红色失败、金色连接中；
- 再次导入时自动为旧记录补齐新增详情字段；
- 同局阵容每次最多补齐 12 场，优先最近对局，避免一次请求过多；
- 本地 JSON 原子保存，每 60 秒后台检查一次新对局。
- 根据客户端 PUUID 自动建立账号档案，不同账号的战绩和统计完全隔离；
- 顶部账号按钮使用与其他操作一致的深色菜单，可查看任意历史账号；
- 只有查看账号与客户端当前账号一致时才允许导入；
- 导入前后双重检查账号，切号过程中不会写入数据；
- 旧版本数据先保留为“未归属数据”，通过 `gameId` 直接核验旧对局详情并自动认领；
- 图标列和“英雄”列共用一个完整表头，数据行仍分别显示头像与英雄名。
- 所有表头使用统一的深色边框绘制，避免系统样式产生白色描边；
- 顶部“使用须知”提供功能说明、非商业使用规则、免责声明和作者信息。

## 运行程序

```powershell
斗魂战绩册.exe
```

请将 `斗魂战绩册.exe` 和 `ArenaTrackerBridge.exe` 放在同一个文件夹。
读取组件由主程序静默调用，不会单独弹出控制台窗口。

## 数据目录

程序数据默认保存在：

```text
%LOCALAPPDATA%\ArenaTrackerCN
```

其中包含：

- `matches.json`：本地对局数据库；
- `settings.json`：客户端目录等本机设置。

备份或迁移时，关闭应用后复制整个 `ArenaTrackerCN` 数据文件夹即可。

## 自动导入条件

1. 通过 WeGame 启动并登录英雄联盟国服客户端；
2. 保持客户端运行；
3. 点击“自动导入”。

如果程序没有自动找到客户端，可点击“客户端目录”，选择包含
`LeagueClient.exe` 的 `LeagueClient` 文件夹。

## 安全说明

本程序只读取英雄联盟客户端在本机提供的赛后历史数据，不读取游戏内存、
不注入游戏进程、不使用驱动，也不会保存客户端临时认证令牌。

## 当前国服识别规则

- `queueId = 1750` 或 `gameMode = CHERRY`；
- `subteamPlacement = 1` 判定为吃鸡；
- 不使用可能误导的普通 `win` 字段。
